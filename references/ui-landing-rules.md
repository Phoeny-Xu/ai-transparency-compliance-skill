# 问卷前端／工具落地注意事项（ui-landing-rules）

> 适用：任何把模式A问卷渲染成网页／表单／对话式 UI／no-code 问卷工具的实现，**以及 agent 在对话中逐题呈现问卷的场景**（对话呈现同受本文件约束，尤指 §1「不暴露内部落盘逻辑」、§2「补充行与示例随主问句同渲染」）。
> 配套资产：`assets/modeA-questionnaire-business.md`（默认皮肤）与 `assets/modeA-questionnaire.md`（判定母版）。本文件只约束「呈现层如何落地为 UI／问卷工具」，**不触碰判定层**——凡源文件已有规定的，一律指针引用、不另立口径；冲突时以源文件为准。
> 设计稿与评审记录：工作区《业务版问卷前端-工具落地注意事项.md》＋《分流默认反转与呈现层降级_执行方案_20260918.md》。
> 修订记录：2026-09-18 建立并随分流反转批部署（§1 扩至话术类、§2 增分流问三部分规则、§7 转为集成记录）；2026-09-18 批G-5 新增 **§6 发出前自检（问卷层门禁）**——§6 ⑤（多选逐项列举）与 ⑦b（高风险锁定题题面完整性）由报告端前移至问卷层，原 §6「集成记录」顺延为 §7。

## 1. 禁止把内部信息暴露给用户（★强制）

- **单选题的选项后不得附加（是）（否）等内部落盘标记。** 题干是单选（如"用户看到的是谁的品牌"），每个选项后挂（是）（否）会误读为"对每一项做二值判断"，且"不确定"无标记造成前后不一致，令用户困惑。
- 内部落盘映射（如"选白标 → B2 落盘为否""选上游品牌 → 不以自己名义"）属于 agent 判定层，只写在【皮肤·落盘映射】备注里，**绝不进题干／选项／UI 标签**。
- 任何"选 X 意味着落盘 Y""该选项对应键 Z"的措辞，一律视为内部信息，不得呈现。
- **适用范围含全部话术，不止题干／选项**：本条同样约束**开场声明、起始分流话术、回显文案、即时校验（弹窗）提示**——凡发到用户眼前的文字，都不得夹带文件路径（如 `assets/modeA-questionnaire.md`）、皮肤命名（"法务版／业务版"）、内部角色词（provider／deployer／covered provider）、落盘键名与值、判定口径。凡话术块，**块内只放用户可见原文，agent 侧注解一律留在块外**。
- 与 `SKILL.md` 2.5 题面锁的「内部指令剥离」白名单属同一分工：剥离项留在源文件备注，不进呈现层。

## 2. 说明／示例补充行必须与主问句一同渲染（★强制）

- **每题的「范围／说明／示例」行**：业务版为降门槛，把法务版"题干内嵌括号示例"拆成了独立的「范围：…」「说明：…」行（典型如 B4②、B2②）。**前端／工具落地时，不得只抓取带"？"的主问句行，必须把紧随其后的范围／说明行一并渲染**，否则用户看不到示例、无从判断。
- **起始分流问（发出问卷前的第一问）必须三部分整体呈现**：题干（"您偏好什么风格的问卷类型，精炼还是通俗易懂？"）、两个选项及其各自括号内**示例**，共三部分一并发出。示例是答题人判断"精炼／通俗"的唯一依据，**不得只发问句、不得剥离或删改示例**；选项标签不得替换为内部资产名。原文见 `SKILL.md` 阶段1 起始分流段与 `assets/modeA-questionnaire-business.md` §一（两处逐字一致）。
- **内嵌判据（2026-09-18 定为正式标准）**：补充行**含举例**（「如…／例如…」）者——该信息属作答前提、不看无法作答——**一律内嵌回题干括号**（恢复法务版风格），从源头杜绝 UI 丢行；**纯口径提示**（如月活口径「最近 30 天内去重」、B1③「有偿无偿均计入」）与**纯说明**（如 B4① 法定通道解释、A6 法域回显说明）保留独立行，由本条第 1 款强制同渲染兜底。**已内嵌**：B4②、B2②（2026-09-18）。
- 反例一（**已修复**）：B4② 主题干在法务版原题括号内即带"如社交、论坛社区、评论、站内传播等"；业务版曾拆到独立「范围：」行，UI 只渲染主问句时会丢示例、用户困惑"什么算平台或功能"——已于 2026-09-18 内嵌回题干括号。
- 反例二：起始分流问若只渲染题干行，"精炼／通俗"对答题人即为无从判断的抽象词，分流失去依据。

## 3. 呈现锁题号索引（内容以源文件为准）

下列题目在源文件中带"整组照搬、不得改写、不得省略示例"的呈现锁要求。**本节只给索引与锁类型，具体文字一律回源文件该题原文取，不在此复制**——避免摘录过期后误导 UI 实现者：

| 题号 | 锁类型 | 源文件落点 |
|---|---|---|
| B4②(a) | 平台类型四类**封闭列举**＋「如…」示例，整组照搬 | BIZ 该题原文 |
| B1③ | 技术锚点（`.safetensors`、`GGUF`）须随题干照搬，**不得泛化**为"如模型文件" | BIZ 该题原文 |
| B6 | 三个限定词（"文本"／"公共利益目的"／"贵司自己发布"）**加粗** | BIZ 该题原文 |
| B9 | 法定概念**定义先行**（情感识别／生物特征分类），须随题干先呈现 | BIZ 该题原文 |
| B3a | **两档摘要**（≤100万／>100万）＋不确定；优先复用A4(a)相同口径，只有口径不同、接近门槛或不确定时才补采详情；不得预设全球最近30日 | BIZ 该题原文 |
| B8-3 | 与 A4(a) 共用**七档尺**，UI 复用组件时口径提示须一并列入 | BIZ 该题原文 |

**规模问题压缩呈现规则（★）**：A4(a)、B3a、B4②(c)使用同一张可复用口径卡；已有数字直接回填，后续题只显示“沿用A4(a)口径／填写差异项”。B4②(c)在平台候选不成立时不呈现12个月数据表；平台候选成立时一次性显示12个月数据、接收用户、创作者/协作者用户和阈值解释字段，不拆成多轮确认。

**同步义务**：源文件（BIZ／LAW）对应题修订时，本索引表须同批核对（题号或锁类型增减都要回填）；本表与源文件冲突时，**以源文件为准**。

## 4. 单选／多选／填空的呈现标识

- **「其它（请补充）___」填写栏内的 placeholder 辅助提示（2026-09-18 采纳，两皮肤一致适用）**：可在填写栏内置灰色提示文案（如 B2② 的「如：客户品牌、白标」），帮助用户判断何种情形填此处。placeholder **非选项增项**，不违反镜像规则，也不改变落盘归一（B2②「其它」仍归 `否`＋记品牌归属事实）。**落点以各皮肤该题是否设「其它（请补充）」填写栏为准**：业务版 B2② 有该填写栏，直接适用；法务版该题为「是／否／不确定」二值单选、**无该填写栏**，故无 placeholder 落点，其白标／客户品牌场景按「否」＋记录品牌归属处理（口径与业务版归一映射一致）。若要求法务版也出现该填写栏，属**母版题面改动**（须先改写该问为「谁的名义」式的多值问，LAW 先行），不在本次落地范围。

- 每题必须标注（单选）/（多选）；数值估算与开放描述保留填空。
- 「其它（请补充）___」「不确定」**是否附加、附加哪一个，逐题以所选皮肤文件该题的选项列为准**（见 BIZ §0.3 第 1 条镜像规则）——各题附加情况本就不统一（如 B3a/B6/B9 不加「其它」，B7 不加「不确定」，B8-1/8-2 仅「是/否」）。**UI 不得隐藏该题选项列中已有的附项，也不得为源题未列的题补加附项。**
- 本节不设"全局固定附项"默认规则；源文件的全局性表述属源文件内部的待理事项，UI 层不放大、不照搬。

## 5. 其他呈现层规则

- 即时校验拒识话术**直接复用源文件原文**，不另写一套（避免出现第三套口径）。例如 B3a 被误用七档尺时的提示，应复用 V3-01 原文。

## 6. 发出前自检（问卷层门禁，对应 `SKILL.md` §6 ⑤／⑦b）

模式A 的 **⑤（多选逐项列举）** 与 **⑦b（高风险锁定题题面完整性）** 在**报告端不可机器化**——报告只见结论、不含当轮题面证据，无从核对「是否完整呈现过」。故二者前移到本层：**每轮问卷发出前**，按 §6.1／§6.2 两张自检表逐项自查；发现缺失的**当轮补问**并记入 `survey_audit.json` 审计记录，不得留到报告端兜底。

> 与报告端的分工：本层管「**当轮是否完整呈现过**」（交互层事实）；报告端 §6 ⑤／⑦b 保留为**人工终判**（复核报告结论与当轮题面一致）。本层**不新增报告端机器码**——报告无题面数据可查。

### 6.1 多选题逐项列举（对应 §6 ⑤）

适用题：**A3／A6／B1①／B1②／B5a**（多选）。

| 检查点 | 要求 |
|---|---|
| 选项集完整 | 与所选皮肤源文件该题选项列**逐项一致**，不增不删、不缩写 |
| 逐项列举 | UI／对话须把全部选项**逐项列出**供多选；**不得**改成单选、**不得**加「全部适用／都涉及」类快捷项替代逐项勾选 |
| 不「按最严口径全列」 | **不得**因保守而把用户未选的选项计为已选。「最严口径」只适用于用户答「不确定」的**范围判断类**；客观事实类按条件式「若X则Y」待核，不推定成立 |
| 「不确定」处置 | 仅答「不确定」的选项可按最严口径，并在报告「假设与不确定项」节标注待核对 |

### 6.2 高风险锁定题题面完整性（对应 §6 ⑦b）

适用题：**A4／B1③／B4②(a)／B6／B9**（即 §3「呈现锁题号索引」与源文件「高风险题锁定标签」所列）。

| 检查点 | 要求 |
|---|---|
| 题干要件 | 与源文件**逐字一致**；不得增删要件、不得改写要件间逻辑关系 |
| 选项集 | 逐项照搬；**封闭列举**与「如…」**示例不得省略**（见 §2、§3） |
| 示例与补充行 | 补充行／示例随主问句**同渲染**（§2）；已内嵌回题干括号者不得再拆出 |
| 锁型落地 | §3 索引**所列**锁型（封闭列举／技术锚点／限定词加粗／定义先行／档尺）逐项落地 |
| 缺失处置 | 发现曾缺失的**当轮补问**并记入审计记录；不得留到报告端由 ⑦b 发现 |
