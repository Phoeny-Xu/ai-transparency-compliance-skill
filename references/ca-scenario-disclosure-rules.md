## 一、适用纪律

1. CAITA门槛、纯文本范围或covered provider资格不得作为本文件规则的总闸门。
2. 各法案分别判定主体、行为、例外、生效日期和罚则，不得串用。
3. 客观事实不确定时，只输出条件式义务和待核项，不得推定事实成立。
4. B10只盘点已实施措施，不进入任何适用性判断。

## 二、BOT Act（B&P Code §§17940–17943）

仅在自动化在线账户被用于与加州自然人在线沟通或互动，且存在误导其人工身份的意图，并为明知欺骗通信内容以促成商品/服务交易或影响选举投票时进入§17941。使用者作出明确、显著且合理设计的bot身份披露时，不承担该条责任。§17942(c)明定本章不向在线平台服务提供者、网站托管或互联网服务提供者施加义务。它不是所有聊天机器人的统一自报规则。

官方来源：`references/sources/CA-SB1001-BOT-Act-chaptered.md`（§§17940–17943；2019-07-01起施行）。

## 三、陪伴型聊天机器人

### 3.1 SB 243与SB 867定义链

- B12先采自然语言界面、适应性类人回应、持续社交/情感设计、多次互动维持关系及排除事实，再派生`B12_companion_status`。
- 游戏、客服、企业运营、生产力/分析、内部研究、技术支持及独立语音助手等排除须逐项核验；混合用途不得因包含排除用途而整体排除。
- 独立语音助手排除同时读取`standalone_voice_device`、`sustains_relationship`和`voice_emotional_output`。
- operator指向加州用户提供陪伴型聊天机器人平台的人（§22601(e)）；不得拿CAITA的covered provider替代。
- SB 867自2027-01-01起对§22601增加toy定义；其§22604.5玩具禁令转`out-of-scope-pointer.md`，不混入透明度义务。

官方来源：`references/sources/CA-SB243-chaptered.md`、`references/sources/CA-SB867-chaptered.md`。

### 3.2 §22602(a)误认真人通知

`B12_human_misidentification_status`仅依据媒介、上下文、身份线索和`fictional_or_ai_framing`派生。当前措施由B10采集，只用于差距分析。

若理性人会被误导为正在与真人互动，operator须依§22602(a)作出明确且显著的“人工生成、非真人”通知。独立于该条件义务，§22604要求在用户可访问平台的应用、浏览器或其它格式披露陪伴型聊天机器人可能不适合部分未成年人。

截至2026-12-31，operator还须对其已知为未成年人的用户履行§22602(c)：披露正在与AI互动；持续互动至少每三小时默认提示休息并再次提示人工生成、非真人；采取合理措施防止特定露骨色情视觉材料或直接要求未成年人参与相关行为。其它自残协议、年度报告和儿童安全事项作为关联义务/专项核验分层呈现，不冒充普通AI身份提示。

SB 243的民事救济见§22605：实际受损者可请求禁令、实际损害或每次违规1,000美元两者较高者，并请求合理律师费和诉讼成本。不得把该罚则套给BOT Act、SB 1050或CAITA。

### 3.3 SB 1119时间状态

| 时间窗 | 基线 |
|---|---|
| 截至2026-12-31 | SB 243现行§22602(a)、(c)及§22604 |
| 2027-01-01至2027-06-30 | §22602修订生效，原(c)删除；§21811生效，但其(b)路径援引的§21812(d)、§21813尚未施行 |
| 自2027-07-01 | §21812、§21812.5、§21813按明文开始施行 |

§21811要求operator二选一：依年龄保证制度确定用户年龄；或把§21812(d)及§21813的儿童保护适用于全部用户。2027-01-01至2027-06-30期间，§21811已生效但其(b)路径援引的保护措施尚未施行，报告须把“条文已生效”和“援引措施未施行”分开，官方无实施解释时不自行补足履行效果。

识别年龄后阻止儿童访问，主要进入§21812(b)的年龄保证公开说明；允许儿童继续使用，才进入§21812(c)/(d)的儿童安全政策、默认设置和危害防护，以及§21813的数据/广告限制。§21814按AB 1405已章化且不晚于2027-01-01生效的正向条件版本处理；§21815是州检察长建立公众投诉机制，不写成运营者自报义务。

§21816的执法与救济独立列示：公共检察官可就过失违法按每名受影响儿童每次最高5,000美元、故意违法最高15,000美元主张民事罚款；符合限定的实际受损儿童可就§21812(d)(1)–(5)请求实际损害等救济。不得与SB 243 §22605的每次违规1,000美元规则合并。

官方来源：`references/sources/CA-SB1119-chaptered.md`；AB 1405条件版本须回leginfo chaptered文本核验。

## 四、SB 1050合成表演者广告

已于2026-09-16章化，普通生效节点为2027-01-01；生效日前写“已制定、尚未生效”。

- 创作者路径：§17610(b)规制“制作并促使在广告媒介发布”的人。广告须属于§17610(a)(1)的交易促成类广告；合成表演者须由生成式AI全部或部分形成真人音频、视听或视觉表演的逼真印象，且不能识别为任何具体自然人。`prominently`仅限§17610(a)(5)三个封闭情形。命中时须以与“this performance features a synthetic performer”或“no human performer is depicted”实质相似的措辞作明确且显著披露。
- 例外：表现性作品广告中的用法与作品内一致；或生成式AI仅用于真人表演者（human performer）的语言翻译/其它无障碍功能。例外中的“仅”不得放宽。
- 广告媒介路径：§17610(e)仅在媒介能够移除/停止传播，且已被送达有管辖权法院的相关命令及足以识别广告的信息时，要求在商业上合理且技术可行的最短时间内移除/停止传播并停止接受后续传播付款。不得给媒介套用创作者披露义务。
- 执法：§17610(f)把违法视为§17500违法并依§17200起章节执行；罚则须回对应执法条文核验，不得套用CAITA或SB 243金额。

官方来源：`references/sources/CA-SB1050-chaptered.md`（§17610）。

## 五、政府和医疗AI通信披露

- SB 896：Government Code §11549.66要求州机构或部门用生成式AI直接就政府服务/福利与个人沟通时，同时提供生成式AI免责声明和联系人类员工的信息/链接。书面偶发通信在开头显著显示，连续在线交互全程显著显示，音频在开始和结束口头提示，视频全程显著显示。官方来源：`references/sources/CA-SB896-chaptered.md`。
- AB 3030：H&S Code §1339.75适用于health facility、clinic、physician's office或group practice office用生成式AI生成涉及患者临床信息的书面/口头通信；须按媒介给出免责声明和联系真人的清楚指引。预约、账单等行政事项不属于patient clinical information；经持证或认证医疗人员阅读并复核的通信适用§1339.75(b)例外。官方来源：`references/sources/CA-AB3030-chaptered.md`。

## 六、AB 1609客服机器人监控

截至2026-09-22官方历史仍为Enrolled、待州长处理；引用前须实时核验。效力键只允许`pending_governor`、`signed_not_effective`、`effective`、`vetoed`、`became_law_without_signature`。未生效时只作前瞻监控。

若成为法律，至少核验：是否为商品/服务销售或交付相关的直接客户服务/技术支持；用户账户地址是否显示加州居民；全美总年营收是否超过5亿美元；是否属于专用员工/B2B渠道、医院特定通信或其它明文排除；是否冒充真人或可能使理性人误认真人；披露、转人工和响应机制。拟议§22626禁止冒充真人，并在理性人可能误认时要求按互动媒介作明确且显著披露；拟议§22628的罚则为首次最高5,000美元、后续每次最高10,000美元且无私人诉权。未生效前不得写成现行义务或现行罚则。

官方来源：`references/sources/CA-AB1609-enrolled.md`（拟议§§22625–22629）。
