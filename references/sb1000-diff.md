# SB 1000 与现行 CAITA 修订方向提示（agent 提示辅助）

> 用途：agent 在加州相关场景生成报告（模式A/B）时，据此向用户提示 SB 1000 的**可能改动方向**，而非逐字对照。
> 状态（截至2026-08-13）：SB 1000 为 CAITA（SB 942 经 AB 853 修正）的修正案，**提案/审议中，尚未生效**（加州议会 Assembly 三读程序，未送州长签署）。
> 铁律1：本文件仅为过渡期提示辅助，**不构成法律文本**。若 SB 1000 已生效，agent 须联网核验官方原文（加州立法官网历史页：https://leginfo.legislature.ca.gov/faces/billHistoryClient.xhtml?bill_id=202520260SB1000）后再输出确定性结论，不得仅凭本文件。

## 可能改动方向（草案已修订过一版，具体条款仍可能继续变动）

> 以下为已公开草案体现的修订方向；加州议会已修订过一版草案（2026年6月9日修订版），不排除具体条款继续被修订。agent 提示时只陈述"方向"，不陈述"将必定如此修改"。

| 方向 | 对应现行条款 | 对 skill 加州义务的影响 |
|------|------------|----------------------|
| 删除"受管辖提供者"（covered provider）月均超100万用户的门槛，仅保留"加州公开可访问" | §22757.1(d) | 适用范围大幅扩大；当前依100万阈值判定"非covered provider"的结论可能翻转（见报告否定判定提示） |
| 取消"提供添加显式标记（manifest disclosure）功能"的义务选项，改为强制 | §22757.3(a) | 显式披露由"可选提供"变"强制" |
| 修改有关嵌入隐式标记（latent disclosure）的义务（如要求标明内容是否由AI生成/修改、字段细化） | §22757.3(b) | 水印/元数据字段要求变化 |
| 重构第三方许可条款（如撤销/中止/终止、豁免监控义务等） | §22757.3(c) | 许可传导义务调整 |
| 将"AI detection tool"改称"disclosure verification tool"并调整功能/隐私规则 | §22757.2 | 工具命名与个人信息处理规则改写 |
| 删除专供非用户生成娱乐内容的豁免 | §22757.5 | 娱乐内容生成/改动企业不再因产品类型豁免 |
| 主张紧急生效（无过渡期） | §22757.6 | 若突发生效须即时合规 |

> 不受影响：§22757.3.1/.3.2/.3.3（大型网络平台/托管平台义务）、§22757.4（罚则）不受 SB 1000 影响。
