> 状态（截至 2026-09-05）：SB 1000 为 CAITA（SB 942 经 AB 853 修正）的修正案，**已通过议会、待州长签署**（Enrolled 2026-08-30；2026-09-02 下午3时提交州长）。属**紧急法案（urgency statute）**，一经签署或超期自动成为法律即**立即生效**。

## 确定性修订对照（Enrolled 逐字核实）

| 修订点 | 现行法（SB 942 经 AB 853） | SB 1000 生效版 | 性质/影响 |
|--------|--------------------------|----------------|----------|
| covered provider 定义 | §22757.1(d)，月访问/用户超 100 万 + 加州公开可访问 | §22757.1(e)，**删除 100 万门槛**，仅留「加州公开可访问」 | 适用范围大幅扩张：从头部企业到几乎所有加州可访问的 GenAI 系统提供者 |
| 定义条整体重编号 | (a)–(p) | 全面重编号；**新增** (b) assistive technology、(l) minor modification；**删除** latent、manifest、personal provenance data；**改写** (n) provenance data（改为符合标准制定组织广泛采纳规范、可互操作的格式） | 术语与义务客体调整 |
| 工具 | AI detection tool | 改名 **disclosure verification tool**；(c) 隐私规则重构为数据最小化；**新增** (d) 不得以提供超必要个人信息为访问条件、(e) 第三方工具通道 | 工具功能与个人信息规则改写 |
| 显式披露选项（manifest） | §22757.3(a)，须向用户提供显式披露选项 | **完全删除**（连 latent/manifest 定义一并删除） | 显式标记不再是法定义务；隐式披露成为唯一强制披露框架 |
| 隐式披露（latent） | §22757.3(b) | §22757.3(a)，重构：**任何**内容（原 AI-generated）、轻微修改除外、provenance data 新定义、**新增 (E) 是否创建/改动、(F) 辅助技术字段（2029 起）**、(2) 永久或极难移除或**篡改**、(3) 与披露验证工具兼容、(4) 符合或可互操作于广泛认可行业标准 | 隐式披露字段与标准要求细化 |
| 第三方许可 | §22757.3(c)，合同传导 + 96 小时撤销 + 被许可人停止使用 | §22757.3(b)，重构：许可时通知 + 72 小时终止/通知 + 被许可人 96 小时整改/停止并报告 + 提供者向总检察长报告 + **无监控义务** | 许可传导机制重构 |
| 总检察长报告机制 | 无 | **新增** §22757.3(c) | 总检察长建立受理报告机制 |
| 虚假辅助技术陈述 | 无 | **新增** §22757.3(d) | 禁止虚假陈述 GenAI 系统主要设计用作辅助技术 |
| 罚则（一般） | §22757.4，含 (c) 被许可方禁令救济 | 删除 (c) 被许可方禁令救济；**新增** (c) 过渡条款、(d) 排除虚假辅助技术陈述 | 罚则结构调整 |
| 虚假辅助技术专项罚则 | 无 | **新增** §22757.4.1：每次 50,000 美元（一般违规 10 倍）、按日计罚、**2029-01-01 废止** | 专项重罚 |
| 豁免 | §22757.5，电子游戏/电视/流媒体/电影/互动体验五类 | **收窄为仅「电子游戏」**；**新增** (b) 辅助技术限时豁免（至 2029-01-01） | 豁免范围收窄 + 辅助技术临时豁免 |
| 生效 | §22757.6，2026-08-02 生效 | 紧急法案条款，**一经签署/自动成为法律即时生效** | 即时生效 |

> **不受影响**：§22757.3.1 / .3.2 / .3.3（大型网络平台 / 托管平台 / 采集设备制造商义务）经 SB 1000 未作修订（仅 §22757.1 定义条重编号影响其引用序号）。

## 更正记录（原"拟议方向"中的两处预测偏差）

1. ❌ 原方向②「取消显式披露选项，**改为强制**」→ ✅ 实际是**完全删除** manifest 披露选项（连 latent/manifest 定义一并删除），latent 成为唯一强制框架。不存在"强制显式标记"。
2. ❌ 原方向⑥「删除娱乐豁免」→ ✅ 实际是**收窄为仅"电子游戏"**（电视/流媒体/电影/互动体验不再豁免，电子游戏仍豁免）。

3. 确定性修订要点（见上表，重点是：①删除 100 万门槛 ②完全删除显式披露选项 ③隐式披露重构 ④第三方许可重构 ⑤工具改名 disclosure verification tool ⑥豁免收窄为电子游戏 ⑦新增辅助技术制度与专项罚则）。
