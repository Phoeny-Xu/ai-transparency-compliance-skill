# survey_audit.json 结构化答案契约

> 当前契约版本：`survey_audit/3`。`survey_audit/1`、`survey_audit/2` 仅作兼容读取；新落盘文件不得继续写旧版本。v3 将B2主问题事实纳入规范对象，修复旧契约只能保存(a)(b)的缺口。

> 定位：`assets/modeA-questionnaire.md` 的**回填确认**环节除回显给用户外，另落一份机器可读的答案文件，供
> `scripts/resolve_triggers.py` 做触发布尔运算、统计详情完整性与答案级校验。过去 A2／B4 一类校验只能靠 agent
> 自觉比对，本契约是其**使能层**。

## 为什么需要它

案例14盲测暴露：注入「全球月活 ≤100万 vs 各法域档位之和远超」时，现有弹窗清单一条都没命中，
agent 只能凭常识补判。要让这类校验可执行，输入必须是结构化的。
**配套要求**：B4②(a) 的「其它（请补充）」一旦填写数字/量级描述，agent 须**强制弹窗补选档位**，
不得把量级信息留在自由文本里——先修输入契约，再写校验（自由文本里的中文量级无法可靠解析）。

## 文件位置与命名

- 工作区：`<报告同目录>/.audit/<报告文件名>.survey_audit.json`
- 该文件属**过程留痕**，不进交付物、不进 skill 三副本同步。

## 结构

**两种结构都收**（读取统一走 `scripts/survey_io.py`，见下节）：

- **嵌套（文档所定形状，推荐）**：元数据外壳 + `answers` 内层，`history` 与元数据分层；
- **扁平（兼容既有资产）**：答案键直接放顶层，元数据键（`schema`/`report`/`session_date`/`history`）并列。

## 字段口径

`A3_functions` 与 `A3_modalities` 是 v2 的规范字段：前者为 `生成`、`检测`、`分析` 的多选数组，后者为生成输出模态数组。纯检测/纯分析产品应保留功能事实并将 `A3_modalities` 置为空，不得把检测或分析当作输出模态。`A3` 仅保留为 v1 兼容镜像；读取 v1 时由 `survey_io.py` 迁移生成这两个字段。

### B12/B13封闭值域

- B12的布尔事实统一为`yes|no|unknown`；`use_cases`只认：`陪伴/虚拟角色`、`客服`、`企业运营`、`基于源信息的生产力或分析`、`内部研究`、`技术支持`、`游戏功能`、`独立语音助手`、`其它`。选择`其它`时须以非空`use_cases_other`保存补充文本，未选择时不得落该键。`human_identity_signals`只认：`自称或暗示真人`、`使用真人姓名或照片`、`使用员工等真人身份`、`叙述第一人称真人经历`、`其它可能造成真人印象的线索`、`以上皆无`、`不确定`；`以上皆无`／`不确定`不得与其它值并存；选择其它线索时须以非空`human_identity_signals_other`保存补充文本，未选择时不得落该键。
- `child_access_policy`只认`allowed|prohibited|not_established|unknown`；`child_access_after_age_check`只认`allow|block|undecided|unknown`；`access_context`只认`general|higher_education_only|workplace_only|mixed|other|unknown`。
- B13的`role`为必填封闭值：`creator|advertising_medium|both|none|unknown`；`role=none|unknown`时对象只保留`role`，不得落卡内后续字段；`advertising_medium`路径只允许媒介法院命令字段，`creator`路径不得包含该字段，`both`才可并存两路字段。`prominent_use`为数组，只认`foreground_demonstration`、`narration_or_commercial_message`、`explain_or_respond_to_commercial_message`、`none`、`unknown`；`none`/`unknown`不得与其它值并存。其余布尔事实统一为`yes|no|unknown`。**agent2（2026-09-28）新增 creator 路径前置分流键 `expressive_work_ad_present`（4a：有无为作品本身做的广告，`yes|no|unknown`）**：`=no` 时 `expressive_work`／`use_consistent_within_work` 不得落键（(d)(4) 例外无适用对象）；`=yes/unknown` 才采集两键。**creator 路径的两项 §17610(d)(4) 要件分别具名落盘：`expressive_work`（该广告是否为表现性作品的广告）与 `use_consistent_within_work`（广告中用法是否与作品本体内的用法一致），不得再合并为单一 `expressive_work_exception` 键**；两键同为`yes`方构成 (d)(4) 例外；第 5 项（`expressive_work`）答`no`时第 6 项不问、`use_consistent_within_work`可不落键（缺键＝未采集，不得反推为`no`）。
- `AB1609_recheck.recheck_required=true`时，`recheck_reason`必须为`AB1609_revenue_near_threshold`，且`recheck_by`为非空复评节点；该对象不表示营收已越线。

### B10 取值域（★两皮肤落盘同值）

`B10_current_practices` 为数组，元素取自下列**落盘规范值**（业务版与法务版题面用词不同，但落盘一律归一至这些规范值，确保 `build_skeleton.py` 与报告模板同键同值消费）：

- `界面文字或语音提示` —— 界面文字/语音提示内容由AI生成（业务版呈现：页面提示）
- `画面角标或可见标记` —— 画面角标、可见标识（业务版呈现：图片视频标记）
- `隐式标识（元数据/水印）` —— 文件嵌元数据或水印（业务版呈现：文件来源信息）
- `仅合同或条款约定` —— 仅在合同/条款中提过（业务版呈现：仅合同里提过）
- `AI交互身份提示` —— B12触发后显示
- `未成年人适龄AI身份提示` —— B12儿童路径触发后显示
- `长时间互动周期提示` —— B12触发后显示
- `合成表演者广告披露` —— B13触发后显示
- `尚未实施` —— 以上均未实施（可单独出现；与上面四项并存时视为「部分实施」）

> 归一铁律：业务版大白话选项（页面提示/文件来源信息/图片视频标记/仅合同里提过/都还没做）须**机械映射**回上述规范值落盘；不得直落大白话原文（否则 `build_skeleton.py` 的集合差运算失配、差距表静默失效）。

### 值域归一规则（★防机器校验静默失效）

- **「不清楚」＝「不确定」**：问卷呈现层用「不确定（按最严口径）」，用户口语答「不清楚」时按同义处理、**落盘一律写 `不确定`**，**不得直落「不清楚」**——否则 `B4_2`／`B6`／`B8-4` 等门控（精确匹配 `{"是","不确定"}`）会漏命中，导致交叉校验静默跳过、骨架漏行（静默失效，最危险）。
- **「其它（请补充）」属开放式事实记录**：自由文本不进入档位枚举，但若填写了数字／量级描述，须强制弹窗补选对应档位（见「为什么需要它」节的配套要求），不得把量级留在自由文本。
- **封闭选项题的通用输入契约（★2026-09-27 用户裁定，普适）**：**适用于所有封闭选项题**——A 组档位题、B 组单选题与多选题、以及各种动态子问；**开放描述字段**（如「其它（请补充）」的补充文本、`*_details.notes`、`*_other`）**不适用**本规则。用户答出**不属于该题选项列**的值时（斜杠 `/`、「无」、「不适用」、「同上」、「都行」、自造标签、简称、截图转述等），**必须「先回问、后归一」，不得无条件自动映射**：
  1. **先回问**——请用户从原选项列选择，或确认归入该题既有的「其它（请补充）」。**截图、简称、自由符号不得直接视为有效选项**（完整清单通道亦同：只认选项编号或粘贴的选项原文，见 `references/ui-landing-rules.md` §6.4）。
  2. **后归一**——确认后才写入规范值域：确属「以上皆无」的，归到该题既有的终结项（多选长清单的整题终结项表述见 §6.4，或题面既有的「以上皆无」「均无」）；确属该题不适用的，**仅当该题选项列设有「不适用」时才落该值**，未设者继续回问澄清；确属选项外的真实情形，才落「其它」。
  3. **history 留痕**——须把**原值（`old`）、确认后的归一值（`new`）、确认时间（`at`）与理由（`reason`）**写入 `history`；「其它」的补充说明亦记入 `reason`。**不覆盖、不静默替换**。
  4. **不得继续流转**——非选项值**不得进入数组、不得触发计算或门控、不得作为隐藏的「其它」值留在答案里**。
  理由：非选项值进入答案后，值域校验、集合差运算与骨架行集合会失配或静默跳过（机理同「不清楚」写入 `B4_2`）。拆卡回退场景另见 `references/ui-landing-rules.md` §6.4 第 6 条。
  > 与「不清楚」口径的接口：`不清楚`／`不确定（按最严口径）` 是**题面既有选项的同义表达**（`_normalise_scalar` 已实现确定性映射，落盘一律 `不确定`），属**规则明文归一**，不按本条回问——二者不得混为一谈：本条约束的是**选项列之外**的值。
- **`B4_2a` 元素级封闭值域（★2026-09-27 用户裁定，立即生效）**：`B4_2a` 为数组，**逐个元素校验**；允许值仅六个——`社交媒体平台`／`文件分享平台`／`群发消息平台`／`独立搜索引擎`／`其它`／`不确定`（前四类＝§22757.1(i)(1)〔SB 1000〕/§22757.1(h)(1)〔现行法〕的法定封闭列举，与 `scripts/lookups.py` 的 `CA_LOP_CLOSED_CATEGORIES` 逐字一致）。**自造值、含补充文本的混合值（如 `其它:…`）、空字符串、标量与混合非法数组一律结构错误（退出码 2）**，不得静默归一或降级，亦不得按最严口径改判为某一法定类别。存量记录须**回看原始问卷事实或回填证据**后方可归一；无法确定的落 `不确定` 并保留待核事实；真正不属于四类的才落 `其它` 并把补充说明写入 `history.reason`（**不新增落盘键**）。现存待修台账见 `chatgpt改进/修订待定事项_20260927_agent3回应_待修台账.md`。

## 校验

```bash
python scripts/resolve_triggers.py <report>.survey_audit.json     # 触发状态＋统计详情和值域校验
python scripts/build_skeleton.py  <report>.survey_audit.json -o 骨架.md   # 生成报告骨架
```

- **读取统一走 `scripts/survey_io.py`**（`resolve_triggers` 与 `build_skeleton` 共用一处实现，禁止各写一份）：
  - 以 `utf-8-sig` 读取，兼容 Windows PowerShell 5.1 `Set-Content -Encoding UTF8` 写出的 BOM；
  - 嵌套与扁平两种结构都解包，结果等价；
  - **结构校验**：顶层须为对象；`schema` 若存在须为 `survey_audit/3` 或兼容读取的 `survey_audit/1`、`survey_audit/2`；解包后答案键须至少含核心答案 A2、A3、A6。未知键、错误类型、错误值域、历史记录缺字段均抛 `AuditFormatError`，调用方返回**退出码 2**，不得退化为「读不到答案＝答案无矛盾」。**本层只判结构与值域**（含数组字段的**元素级**值域，如 `B4_2a` 的六值封闭白名单）；跨题分支条件（如 F-4 的「平台候选成立时门槛口径卡不得缺席」，前件在 `B4_2`）属答案级语义校验，落 `resolve_triggers.cross_check_scale`（退出码 1），不在此层重复实现——同一缺陷不得出现两个层级/两个退出码。
- **内部不变量**：标 `always=True` 的触发行（B2）必须解析为触发，否则同样以退出码 2 中断。该断言用于区分「答案没读到」与「答案本身无矛盾」。
- 退出码：`0=通过`；`1=答案级问题：统计详情不完整／能力与模态矛盾／答案值无法识别`（须即时弹窗澄清后修订 `answers` 并追加 `history` 记录；值域无法识别与其他答案级问题同码，勿把拒识读成规模矛盾）；`2=未执行`（输入缺失／结构不符／不变量违反）。
- 交叉校验：**B3a/A4a/B4_2c 只有在统计对象、地域、周期和去重方法一致时才可比较；旧版摘要不作硬性规模矛盾**；`B4_2c_details`若声明逐月历史，必须能识别此前12个月数据；**B5a（勾选的高仿真能力）× A3（输出模态）**仍执行单向防过度勾选：所勾能力所需模态在 A3 中完全不存在即报矛盾；反方向“漏勾”不自动校验。
- 触发状态逐行打印，并附「已识别答案键 n 个」，供与 agent 自述的触发结论对勘。
