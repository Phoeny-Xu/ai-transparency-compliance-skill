# survey_audit.json 结构化答案契约

> 当前契约版本：`survey_audit/2`。`survey_audit/1` 仅作兼容读取并自动迁移；新落盘文件不得继续写 v1。

> 定位：`assets/modeA-questionnaire.md` 的**回填确认**环节除回显给用户外，另落一份机器可读的答案文件，供
> `scripts/resolve_triggers.py` 做触发布尔运算、统计详情完整性与答案级校验。过去 A2／B4 一类校验只能靠 agent
> 自觉比对，本契约是其**使能层**。

## 为什么需要它

案例14盲测暴露：注入「全球月活 ≤100万 vs 各法域档位之和远超」时，现有弹窗清单一条都没命中，
agent 只能凭常识补判。要让这类校验可执行，输入必须是结构化的。
**配套要求**：B4②(a) 的「其它（请补充）」一旦填写数字/量级描述，agent 须**强制弹窗补选档位**，
不得把量级信息留在自由文本里——先修输入契约，再写校验（自由文本里的中文量级无法可靠解析）。

## 文件位置与命名

- 工作区：`<报告同目录>/.audit/<报告文件名>.survey_audit.json`
- 该文件属**过程留痕**，不进交付物、不进 skill 三副本同步。

## 结构

**两种结构都收**（读取统一走 `scripts/survey_io.py`，见下节）：

- **嵌套（文档所定形状，推荐）**：元数据外壳 + `answers` 内层，`history` 与元数据分层；
- **扁平（兼容既有资产）**：答案键直接放顶层，元数据键（`schema`/`report`/`session_date`/`history`）并列。

## 字段口径

### v2 功能/模态契约

`A3_functions` 与 `A3_modalities` 是 v2 的规范字段：前者为 `生成`、`检测`、`分析` 的多选数组，后者为生成输出模态数组。纯检测/纯分析产品应保留功能事实并将 `A3_modalities` 置为空，不得把检测或分析当作输出模态。`A3` 仅保留为 v1 兼容镜像；读取 v1 时由 `survey_io.py` 迁移生成这两个字段。

| 字段 | 取值 | 说明 |
|---|---|---|
| `A3` | 文本／图像／音频／视频／虚拟场景／3D／数字人/虚拟人 | 多选数组；空数组表示非生成式 |
| `A4a` | `0`／`趋零`／`<1万`／`1-10万`／`10-100万`／`100万-1000万`／`1000万+`／`不确定` | 法域规模摘要；不再固定推定去重、地域或30日窗口 |
| `A4a_details` | 对象，可按需补充 | 按法域记录统计对象、统计地域、统计周期、是否去重、原始数值和证据来源；若同一口径已在B3a记录，可复用，不重复询问 |
| `A4b` | 主动提供／被动可达／不确定 | 加州轮仅作事实记录，不得作为加州适用性判据 |
| `A4c` | 按法域的字符串数组 | 法域连接点辅助因素；“未发现该因素”和“尚未核实”分开记录 |
| `A6` | 中国大陆／欧盟／加州 | 只作**法域触发条件**；A4 恒为真、不得作触发条件（画像键 A3 等可作复合条件） |
| `B3a` | `≤100万`／`>100万`／`不确定` | covered provider 门槛摘要；不预设全球口径、统计周期或去重方法 |
| `B3a_details` | 对象，可按需补充 | 记录 monthly visitors or users 的对象、地域、周期、去重、原始数值和证据来源；与A4(a)同口径时允许引用A4a_details |
| `B4_2c_details` | 对象，平台候选成立时采集 | 以一次性口径卡记录large online platform此前12个月逐月数据、接收分发内容用户、创作者/协作者用户及统计方法；与A4(a)/B3a相同的字段只填差异项 |
| `history` | 数组 | 旧答案＋更正时间＋原因；**不覆盖、不静默替换**（modeA-questionnaire「答案历史」★强制） |
| `B10_current_practices` | 数组，取值域见下方「B10 取值域」；空数组或含 `尚未实施` 表示未实施任何透明度标识措施；**仅 A3 含生成模态（非空数组）的产品采集**（B10 触发门控，纯分析型不问） | 现状盘点（B10）：产品当前已实施的「让人知道内容来自 AI」的措施；用于报告「已实施 vs 待补齐」差距项 |
| `B11_cop` | 对象：`status` 取 `已签署`／`计划签署`／`未签署`／`不确定`；`sections` 为 `Section 1`／`Section 2` 数组 | 欧盟CoP客观签署事实；A6含欧盟时采集。已签署/计划签署须至少一个Section；未签署须空数组；不确定不得推定已签署 |

### B10 取值域（★两皮肤落盘同值）

`B10_current_practices` 为数组，元素取自下列**落盘规范值**（业务版与法务版题面用词不同，但落盘一律归一至这些规范值，确保 `build_skeleton.py` 与报告模板同键同值消费）：

- `界面文字或语音提示` —— 界面文字/语音提示内容由AI生成（业务版呈现：页面提示）
- `画面角标或可见标记` —— 画面角标、可见标识（业务版呈现：图片视频标记）
- `隐式标识（元数据/水印）` —— 文件嵌元数据或水印（业务版呈现：文件来源信息）
- `仅合同或条款约定` —— 仅在合同/条款中提过（业务版呈现：仅合同里提过）
- `尚未实施` —— 以上均未实施（可单独出现；与上面四项并存时视为「部分实施」）

> 归一铁律：业务版大白话选项（页面提示/文件来源信息/图片视频标记/仅合同里提过/都还没做）须**机械映射**回上述规范值落盘；不得直落大白话原文（否则 `build_skeleton.py` 的集合差运算失配、差距表静默失效）。
### 骨架生成另读字段（`scripts/build_skeleton.py`）

下列字段仅在生成报告骨架时被读取，用于决定**行集合**（哪些环节、哪些法规行出现）：

| 字段 | 取值 | 影响的行 |
|---|---|---|
| `A1` | 自研／部分自研／授权接入／开源微调 | 义务总览「模型自研自训」「上游模型接入」行 |
| `A2` | B2C／B2B／混合模式／仅内部使用／不确定 | 待核事实清单（不确定时）；`仅内部使用` 为 `resolve_triggers` 精确匹配值（门控 `not in (None,"仅内部使用")`），漏写会导致 B1／B4 误触发，务必照写 |
| `B1_hardware` | `true`/`false` | 义务总览「硬件设备制造（采集设备）」行 |
| `B1_3` | 是／否／不确定 | 义务总览「生成式人工智能系统托管平台运营（下载站）」行（加州 §22757.1(g) 角色；案例20盲测暴露漏行——V3-03） |
| `B1_4` | 是／否／不确定 | 义务总览「应用程序分发平台运营」行 |
| `B4_2` | 是／否／不确定 | 义务总览「内容传播平台运营」行 |
| `B4_2c` | ≤100万／100万-200万／>200万／不确定 | 待核事实清单（不确定时） |
| `B6` | 是／否／不确定 | 待核事实清单（不确定时） |
| `SB1000_status` | 待签署／已签署／否决／超期自动生效 | 效力核验记录 SB 1000 行与义务基准（同源 `lookups.sb1000_baseline`） |
| `B10_current_practices` | 数组（见「B10 取值域」） | 现状盘点节「已实施 vs 待补齐」块（build_skeleton 机械生成：列已填报现状＋结构化待补齐提示）；A3 为空（纯分析型）或未采集 B10 时不生成该块 |

> 骨架只写「行主键＋占位符」，**不写任何法律定性**；行内结论由 agent 依规则库填写。

### 值域归一规则（★防机器校验静默失效）

- **「不清楚」＝「不确定」**：问卷呈现层用「不确定（按最严口径）」，用户口语答「不清楚」时按同义处理、**落盘一律写 `不确定`**，**不得直落「不清楚」**——否则 `B4_2`／`B6`／`B8-4` 等门控（精确匹配 `{"是","不确定"}`）会漏命中，导致交叉校验静默跳过、骨架漏行（静默失效，最危险）。
- **「其它（请补充）」属开放式事实记录**：自由文本不进入档位枚举，但若填写了数字／量级描述，须强制弹窗补选对应档位（见「为什么需要它」节的配套要求），不得把量级留在自由文本。

### 题号↔答案键映射表（V3-03 补，防静默缺口）

问卷用圈码题号（如 B1①…⑤），契约用下划线键名。**落盘时按下表转换；键名打错（如 B1_5）会被 `survey_io._looks_like_answer_key` 按 `A×/B×`（字母＋数字）形态放行、不报错**——agent 落盘后应以本表回查一遍：

| 问卷题号 | 契约键名 | 备注 |
|---|---|---|
| A1／A2／A3／A6／A7 | 同名 | A4 为分轮采集，拆为 `A4a`（量级摘要）/`A4a_details`（统计口径）/`A4b`（触达方式）/`A4c`（辅助因素），无 `A4` 裸键 |
| A5 | 同名（如启用） | 增量题，暂未启用 |
| B1① 产品形态 | `B1_1` | 数组 |
| B1② 分发渠道 | `B1_2` | 数组 |
| B1③ 权重/源码下载 | `B1_3` | 是/否/不确定 |
| B1④ 自营商店 | `B1_4` | 是/否/不确定 |
| B1①（硬件） | `B1_hardware` | 布尔 |
| B2 两问 | `B2` | 结构化对象/字符串（关系＋名义）；(a)(b) 两问均并入 `B2` 对象，**不得另立 `B2_a`／`B2_b` 顶层键**（`survey_io` 按前缀放行但不报错，属静默缺口）。**子键名规范（V-2）**：`(a)`／`(b)` 两问在 `B2` 对象内的子键名统一为 `a`／`b`（全仓一致），**不得使用 `B2_a`／`B2_b`／`marking`／`contract` 等变体** |
| B3a | `B3a`＋`B3a_details` | 摘要三值；详情保存对象、地域、周期、去重、原始值和证据 |
| B4① | `B4_1` | 含两个子问。子问2「无显式标识内容申请渠道」**仅 A6 含中国时必问**；A6 不含中国时不问、落 `不适用`（agent 标注，与 `B8_4` 惯例一致）。**子问2＝有 → 消费点**：*提供不含显式标识内容时须*——①用户协议载明标识义务与使用责任；②留存提供对象信息等日志不少于六个月（标识办法第9条，**许可性规范**，非无条件义务）。＝无／不确定 → 不触发该条 |
| B4② | `B4_2`（是否运营平台）/`B4_2a`（平台类型）/`B4_2b`（分发功能）/`B4_2c`（量级摘要）/`B4_2c_details`（逐月详情） | B4②(a)(b)(c) 对应 2a/2b/2c；摘要不得替代逐月详情 |
| B5a／B5b | 同名 | B5b 的交互布尔为 `B5b_interactive` |
| B6／B7／B9 | 同名 | B8 拆为 `B8_1`～`B8_4`；`B8_4` 值域为封闭五值：是／否／部分完成／不适用／不确定（**不含「其它」**），无脚本消费，属文档化值域，落盘须严格归一至这五值 |
| B10 现状盘点 | `B10_current_practices` | 业务版与法务版**均采集**（题面用词不同，落盘同键同值，见「B10 取值域」）；数组，不得自创 `B10_a` 等子键（`survey_io` 按 B 前缀放行但不报错，属静默缺口——子键会被计入「已识别答案键」却无人消费） |
| B11 CoP签署事实 | `B11_cop` | 对象；`status` 与 `sections` 封闭值域。用户只确认签署事实，不判断provider/deployer；个案矩阵的 `signatory` 必须与本字段一致 |

## 校验

```bash
python scripts/resolve_triggers.py <report>.survey_audit.json     # 触发状态＋统计详情和值域校验
python scripts/build_skeleton.py  <report>.survey_audit.json -o 骨架.md   # 生成报告骨架
```

- **读取统一走 `scripts/survey_io.py`**（`resolve_triggers` 与 `build_skeleton` 共用一处实现，禁止各写一份）：
  - 以 `utf-8-sig` 读取，兼容 Windows PowerShell 5.1 `Set-Content -Encoding UTF8` 写出的 BOM；
  - 嵌套与扁平两种结构都解包，结果等价；
  - **结构校验**：顶层须为对象；`schema` 若存在须为 `survey_audit/2` 或兼容读取的 `survey_audit/1`；解包后答案键须至少含核心答案 A2、A3、A6。未知键、错误类型、错误值域或历史记录缺字段均抛 `AuditFormatError`，调用方返回**退出码 2**，不得退化为「读不到答案＝答案无矛盾」。
- **内部不变量**：标 `always=True` 的触发行（B2）必须解析为触发，否则同样以退出码 2 中断。该断言用于区分「答案没读到」与「答案本身无矛盾」。
- 退出码：`0=通过`；`1=答案级问题：统计详情不完整／能力与模态矛盾／答案值无法识别`（须即时弹窗澄清后修订 `answers` 并追加 `history` 记录；值域无法识别与其他答案级问题同码，勿把拒识读成规模矛盾）；`2=未执行`（输入缺失／结构不符／不变量违反）。
- 交叉校验：**B3a/A4a/B4_2c 只有在统计对象、地域、周期和去重方法一致时才可比较；旧版摘要不作硬性规模矛盾**；`B4_2c_details`若声明逐月历史，必须能识别此前12个月数据；**B5a（勾选的高仿真能力）× A3（输出模态）**仍执行单向防过度勾选：所勾能力所需模态在 A3 中完全不存在即报矛盾；反方向“漏勾”不自动校验。
- 触发状态逐行打印，并附「已识别答案键 n 个」，供与 agent 自述的触发结论对勘。
